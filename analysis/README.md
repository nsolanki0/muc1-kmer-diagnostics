Analysis
This directory contains the downstream analyses performed on the simulated MUC1 sequencing data.
The analyses consist of:

machine-learning pipelines using k-mer representations;
targeted analyses investigating specific modelling approaches or experimental settings;
methodological analyses examining properties of the data and model behaviour;
a conventional VNtyper2 analysis used as a baseline for comparison with the machine-learning approach.
Analysis workflow
The processed sequencing reads generated by ../data_generation/ are used as input to both analysis approaches:
                 Processed reads
                       │
             ┌─────────┴─────────┐
             ↓                   ↓
      k-mer feature          VNtyper2
        generation            baseline
             ↓                   ↓
      Machine-learning       Conventional
          analyses             analysis
             └─────────┬─────────┘
                       ↓
                   Comparison

K-mer feature generation is performed separately in ../feature_generation/. The resulting feature tables are then used by the machine-learning analyses in this directory.
Directory structure
pipelines/
Contains the main machine-learning analysis pipelines.
These scripts implement the primary modelling approaches investigated in the project, including:

within-domain analysis;
domain transfer;
domain adaptation;
domain-adversarial neural networks;
hashed k-mer representations.
These scripts represent the principal analysis workflows used to evaluate the proposed machine-learning approach.
targeted_analyses/
Contains analyses designed to investigate specific questions or modelling choices rather than representing the main end-to-end pipelines.
Examples include:

PCA-based analysis;
random-forest analyses;
experiments involving artificial mislabelling.
These analyses provide additional evaluation or investigation of particular aspects of the modelling approach.
methodological_analyses/
Contains analyses investigating methodological properties of the data or modelling setup.
The current analyses include:

bimodality/
Investigates the effect of bimodality and its removal on domain-transfer performance.
family_haplotype_overlap/
Investigates the effect of family/haplotype overlap under different data-splitting and evaluation settings.
baseline/
Contains the conventional analysis used as a reference point for evaluating the machine-learning approach.
The current baseline is based on VNtyper2:

run_vntyper2.sh — runs VNtyper2 on the generated samples.
extract_variant_coverage.sh — extracts and summarises variant-coverage information from the VNtyper2 results.
VNtyper2 is not part of the machine-learning pipeline. It provides a conventional analysis against which the k-mer-based machine-learning results can be compared.
Relationship to other directories
The analysis workflow depends on outputs generated by the preceding stages of the repository:
data_generation/
       ↓
processed sequencing reads
       ↓
feature_generation/
       ↓
k-mer feature tables
       ↓
analysis/pipelines/
analysis/targeted_analyses/
analysis/methodological_analyses/

The VNtyper2 baseline uses the generated sequencing samples independently of the k-mer feature-generation step.
Reproducibility
The analysis scripts are designed to operate in the computational environment specified for each analysis. Software environments and their dependencies are documented in ../environment/.
Many workflows are executed using SLURM to process multiple samples or experiments in parallel.
